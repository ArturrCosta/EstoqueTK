BANCO

usuarios
  id (PK)
  usuario (UNIQUE)
  senha (hash)

produtos
  id (PK)
  usuario_id (FK -> usuarios.id)
  nome
  categoria
  quantidade
  preco
  estoque_minimo
  UNIQUE (usuario_id, nome)

movimentacoes
  id (PK)
  usuario_id (FK -> usuarios.id)
  produto_id (FK -> produtos.id, pode ser NULL apos exclusao)
  produto_nome
  tipo
  quantidade
  data_hora

ISOLAMENTO DE DADOS

Cada produto e cada movimentacao tem um usuario_id. O DatabaseManager guarda
current_user_id apos login e filtra as consultas por esse id. Dados antigos
sem proprietario sao migrados para o admin para preservar o estoque existente.
Novas contas comecam sem produtos e sem historico proprio.
