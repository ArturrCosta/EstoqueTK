# Checklist final de entrega

## Funcionamento

- [ ] MySQL ligado.
- [ ] `python main.py` abre sem erro.
- [ ] Login `admin` / `admin123` funciona.
- [ ] Dashboard carrega os indicadores.
- [ ] Dashboard carrega o grafico.
- [ ] Novo produto funciona.
- [ ] Categoria mostra as existentes e aceita uma categoria nova digitada.
- [ ] Listagem de produtos funciona.
- [ ] Edicao funciona.
- [ ] Exclusao funciona.
- [ ] Cadastro com quantidade inicial registra ENTRADA automaticamente.
- [ ] Aumento de quantidade registra ENTRADA pela diferenca.
- [ ] Reducao de quantidade registra SAIDA pela diferenca.
- [ ] Exclusao registra SAIDA da quantidade restante e preserva o historico.
- [ ] Quantidade nao pode ficar negativa.
- [ ] Historico de movimentacoes aparece.
- [ ] `error.log` e atualizado quando ocorre uma excecao real.

## Antes da apresentacao

- [ ] Personalizar nome, cores e fontes.
- [ ] Escolher quais produtos de exemplo vao ficar no banco.
- [ ] Fazer um cadastro de teste e remove-lo antes da apresentacao, se necessario.
- [ ] Fazer um ensaio do roteiro.
- [ ] Conferir os dados de conexao em `database.py` no computador da apresentacao.
- [ ] Atualizar o GitHub com a versao final.
- [ ] Levar o `banco.sql` junto do projeto.
- [ ] Levar a documentacao e os slides em PDF.
